# E-Commerce Website

This project is a full stack E-Commerce Website developed to provide an easy and smooth online shopping experience. Users can create accounts, explore products, add products to cart, and manage their shopping activities through a simple and attractive interface.

## Features

- User Registration and Login
- Product Listing
- Add to Cart Functionality
- Remove Products from Cart
- User-wise Cart Management
- Responsive Design
- Backend Integration
- Database Connectivity

## Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Python
- Flask

### Database
- SQLite / MySQL

## Project Goal

The main goal of this project is to understand full stack web development concepts and build a functional shopping platform with proper frontend and backend integration.
